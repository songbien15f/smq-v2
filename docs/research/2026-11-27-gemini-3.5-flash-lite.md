# Research — Gemini 3.5 Flash-Lite as SmartQuote's single AI provider

Accessed 2026-11-27 from the official Gemini API docs (`ai.google.dev` now redirects to
`aistudio.google.com/docs`; the Markdown copies at `<page>.md` are the same text). Each fact
below cites its page. Nothing here is from memory. Nothing was sent to the API: no probe ran.

## 1. Model

Source: https://aistudio.google.com/docs/models/gemini-3.5-flash-lite (page says "Latest update July 2026")
and https://aistudio.google.com/docs/models

| Property | Value |
|---|---|
| Model code | `gemini-3.5-flash-lite` (Stable / GA) |
| Inputs | text, image, video, **audio**, PDF |
| Output | text |
| Token limits | 1,048,576 input / 65,536 output |
| Supported | structured outputs, function calling, thinking, context caching, batch, flex/priority |
| Not supported | **Live API** (no streaming voice); use `gemini-3.5-transcribe-live` for that |

On the models page, related models:
- `gemini-3.5-transcribe` / `gemini-3.5-transcribe-live` is a dedicated speech-to-text model:
  - 85+ languages, diarization, word timestamps;
  - **custom vocabulary speech biasing**;
  - audio up to 1 h per request.
  - Source: https://aistudio.google.com/docs/models/gemini-3.5-transcribe
- `gemini-2.5-flash` is routed to 3.5 Flash-Lite from 2026-12-01.
- `gemini-2.5-flash-lite` is open to existing users only.

## 2. Price (Gemini Developer API)

Source: https://aistudio.google.com/docs/models/gemini-3.5-flash-lite (pricing section)

| | Free tier | Paid tier (per 1M tokens) |
|---|---|---|
| Input (text / image / video / audio) | free | $0.30 (audio costs the same as text) |
| Output, thinking included | free | $2.50 |
| Context caching | — | $0.03 |
| "Used to improve our products" | **Yes** | **No** |

Rough per-use cost, derived from the 32 tokens/s audio rate in §3:
- One 60 s voice note is about 1,920 input tokens, roughly $0.0006.
- A typical assistant turn is about 3–6k input tokens (system prompt + design context + schema) plus 300–800 output tokens, roughly $0.001–0.004.

These are estimates, not measured.

## 3. Audio input

Source: https://aistudio.google.com/docs/audio

- Supported MIME types: `audio/wav`, `audio/mp3`, `audio/aiff`, `audio/aac`, `audio/ogg`,
  `audio/flac`, `audio/mpeg`, `audio/m4a`, `audio/l16`, `audio/opus`, `audio/alaw`,
  `audio/mulaw`, **`audio/webm`**.
  - **`audio/mp4` is not on the list.** Safari's MediaRecorder produces it. The container is the
    same as `.m4a`, so map `audio/mp4` to `audio/m4a`. This mapping is not verified: a probe must
    confirm it.
  - The API reference types `inlineData.mimeType` as `audio/*`.
- Inline audio (`inlineData` base64) is allowed while the whole request is ≤ 20 MB. Anything larger
  goes through the Files API. SmartQuote's 1 MB cap is far under this.
- Audio costs **32 tokens per second**. One prompt takes up to 9.5 h. Audio is downsampled to
  16 Kbps and mixed to mono.
- To get a transcript you ask for one in the prompt. Structured output works with audio input.

## 4. Endpoints and auth

Sources: https://aistudio.google.com/api-reference/generate-content,
https://aistudio.google.com/docs/interactions-overview, https://aistudio.google.com/docs/openai

The docs describe three ways to call the model:

| API | Status | Note |
|---|---|---|
| `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent` | "legacy but fully supported" | Stateless; nothing is stored. |
| `POST https://generativelanguage.googleapis.com/v1beta/interactions` | GA, recommended since June 2026 | **Stores requests by default (`store: true`)**; `store: false` opts out. Examples send the header `Api-Revision: 2026-05-20`. |
| OpenAI-compat `https://generativelanguage.googleapis.com/v1beta/openai/` | **beta** | No `/audio/transcriptions` (audio goes in as `input_audio`). Unknown parameters are silently ignored. |

- **Auth:** header `x-goog-api-key: <key>`. The key stays on the server.
- Key types, from https://aistudio.google.com/docs/api-key.md?generate-content=true:
  - Since 2026-05-28 new keys are "authorization keys", bound to a service account.
  - **Requests from unrestricted standard keys are rejected.**
  - A standard key works only when it has explicit restrictions.
- generateContent request shape:
  - `systemInstruction: {parts:[{text}]}`;
  - `contents: [{role:'user'|'model', parts:[{text}|{inlineData:{mimeType,data}}]}]`;
  - `generationConfig: {responseMimeType, responseJsonSchema, thinkingConfig:{thinkingLevel}, maxOutputTokens}`.
- generateContent response shape:
  - `candidates[0].content.parts[].text`;
  - `candidates[0].finishReason`;
  - `promptFeedback.blockReason`;
  - `usageMetadata`;
  - `modelVersion`.

## 5. Structured output

Source: https://aistudio.google.com/docs/structured-output.md?generate-content=true

- Send `responseMimeType: "application/json"` and `responseJsonSchema: <JSON Schema>`. The REST
  field is `responseJsonSchema`; the docs build it with `z.toJSONSchema(...)` or Pydantic
  `model_json_schema()`.
- What the subset supports:
  - types `string`, `number`, `integer`, `boolean`, `object`, `array`;
  - `null` through a type array (`["string","null"]`);
  - `properties`, `required`, `additionalProperties`, `enum`, `format`, `minimum`/`maximum`,
    `items`, `prefixItems`, `minItems`/`maxItems`, `anyOf`, `title`, `description`.
- Unsupported keywords are ignored, for example `minLength`, `maxLength` and `uniqueItems`.
- **Very large or deeply nested schemas are rejected with 400 INVALID_ARGUMENT.** `maxItems` is
  implemented by expanding the item schema once for each allowed position, so `maxItems: 10` over a
  15-branch `anyOf` is a size risk.
- The output is guaranteed to be syntactically valid JSON that matches the schema. Values must still
  be validated by the application.

## 6. Gemini 3.5 Flash-Lite migration rules

Source: https://aistudio.google.com/docs/whats-new-gemini-3.6.md?generate-content=true and
https://aistudio.google.com/docs/thinking

- `temperature`, `top_p` and `top_k` are **deprecated and ignored** for 3.6 Flash, 3.5 Flash-Lite
  and later models. They "will return 400 in future generations". **Do not send them.**
- **A request whose last turn is a non-empty `model` turn returns HTTP 400** (prefill is no longer
  allowed).
- `candidate_count` is not supported.
- Thinking defaults to `minimal` on 3.5 Flash-Lite. The levels are `minimal | low | medium | high`.
  Thinking tokens are billed as output.

## 7. Rate limits

Source: https://aistudio.google.com/docs/rate-limits

- Limits are measured as RPM, TPM (input) and RPD, **per project, not per key**. RPD resets at
  midnight Pacific.
- The model's own numbers are not on the page: "can be viewed in Google AI Studio"
  (https://aistudio.google.com/rate-limit). They have **not been read yet**, because that needs the
  user's own sign-in.
- Spend-based limits apply over a rolling 10 minutes:

  | Tier | Spend limit per 10 min | Billing cap |
  |---|---|---|
  | Tier 1 | $10 | $250 |
  | Tier 2 | $200 | $2,000 |
  | Tier 3 | $200 | — |

  Breaking any limit returns `429 RESOURCE_EXHAUSTED`.
- To reach Tier 1, link a billing account. Tier 2 needs $100 paid plus 3 days.

## 8. Errors

Source: https://aistudio.google.com/docs/api-errors.md?generate-content=true

| HTTP | Status | Retry? |
|---|---|---|
| 400 | INVALID_ARGUMENT / FAILED_PRECONDITION (free tier not available in the region) | no |
| 402 | RESOURCE_EXHAUSTED (prepay credit used up) | **no** ("Don't retry") |
| 403 | PERMISSION_DENIED (bad, leaked or unrestricted key; project needs verification) | no |
| 404 | NOT_FOUND | no |
| 429 | RESOURCE_EXHAUSTED (rate or spend limit) | yes, after a short wait |
| 499 | CANCELLED (the client closed the connection) | — |
| 500 | INTERNAL (sometimes "input context too long") | yes, once |
| 503 | UNAVAILABLE (overloaded) | yes, once, or switch model |
| 504 | DEADLINE_EXCEEDED | larger timeout, or smaller input |

## Live probe, 2026-11-27

`scripts/probe-gemini.mjs` was run with the user's permission: four calls in all, about 530 tokens, well
under one cent. The audio was a Windows text-to-speech clip saying "Make it nine metres wide and add a
roller door on the front", sent as WAV. No guest data was sent.

| Call | Result |
|---|---|
| Turn with `OPS_SCHEMA` exactly as it was (`maxItems: 10` over 15 `anyOf` branches) | **400 INVALID_ARGUMENT**: "the specified schema produces a constraint that has too many states for serving" |
| The same turn with `maxItems` dropped from the ops list (`geminiSchema` in `apps/api/src/lib/ai/schemas.ts`) | **200**, valid JSON `{"message":…,"needsConfirm":false,"ops":[{"op":"setSpan","mm":9000}]}` |
| STT, `audio/wav`, 3.9 s clip | **200**, "Make it 9 m wide and add a roller door on the front." (97 audio tokens) |
| Repair with `REPAIR_JSON_SCHEMA` (`maxItems: 2` over strings kept) | **200**, valid JSON |

What this settles:
- **The key works.** It is an authorization key (`AQ.` prefix), and the requests ran on `serviceTier: standard`.
- **`OPS_SCHEMA` must not carry `maxItems` on Gemini.** `parseOps` still caps the list at ten.
- **Audio costs about 25 tokens per second here,** a little under the documented 32.
